Sobre o projeto

Quiz de Rock

Perguntas sobre a história, os álbuns e os músicos da banda de Seattle, com feedback a cada resposta.

Dashboard

Gráficos feitos com Chart.js mostram seu último placar e a evolução das suas tentativas, salvas no banco de dados.

API Dat-Acqu-Ino

O dashboard também exibe leituras de um sensor Arduino, obtidas pela API do projeto Dat-Acqu-Ino.
